Background play (music)
Keep music playing when your phone screen locks or you switch apps. Turning this on disables the animated bar visualizer for music — the two don't work together on most mobile browsers, since the bars require rerouting audio through a connection that phones tend to cut when the screen locks. Off by default. If you've already played a song with the bars showing earlier in this browser session, reload the page after turning this on so it takes full effect.

Desktop app

Download a launcher that opens Lan flix in its own window, no browser bar — pick your OS:

Linux Windows macOS

Each is a small zip containing a launcher script (not an installer) plus a README with setup steps. Linux: unzip, move lanflix.desktop into ~/.local/share/applications/. Windows: unzip, double-click lanflix.bat (or make a shortcut to it). macOS: unzip, double-click lanflix.command (allow it once in System Settings → Privacy & Security if blocked). These point at this server's current LAN address — if that address ever changes, restart the server once to regenerate them.

Controller

D-pad / left stick always navigates. Remap the action buttons below — click Remap, then press the button you want on your controller.

Cache nodes (LAN)

Optional helper servers you run on other machines around the house to cache videos closer to where they're watched. Playback automatically uses the fastest-responding one when available. Private-folder videos are never cached.

Force cache node playback
Skip the speed race and always use a discovered cache node for eligible videos, even if it hasn't been confirmed as the fastest. Useful for testing whether a cache node actually works. Falls back to the main server if none are discovered at all, or for private-folder videos.
